# 方寸

方寸是一个为大学生活和科研工作设计的本地优先个人中枢。它把“要不要做”交给四象限，把“什么时候做”交给课表和截止日期，把长期目标拆成可执行的下一步。

## 已实现的功能

- 四象限任务：重要且紧急、重要不紧急、紧急不重要、不紧急不重要
- 每天、工作日、每周和每月循环任务，完成后自动生成下一次事项
- 中文自然语言智能收集：一句话识别任务、日程、课程、项目、起止时间、截止时间、提醒、象限和关联对象
- 以“今天”为默认执行首页：下一安排、最多 3 项可解释 Focus、稍后日程、最近 DDL 与当天完成进度形成连续工作流
- Focus 会综合逾期、DDL、重要/紧急、项目风险、预计耗时和用户固定状态；可固定、移除、替换或稍后处理
- 长期项目驾驶舱：多个里程碑、多个可执行行动、计划节点完成率、时间消耗进度和落后预警；下一行动直接进入 Today 候选
- 统一年历、月历、周历和日历：课程、任务、DDL 与节假日共用同一时间体系；手机默认日视图，电脑默认月视图
- 页面顶部实时显示当前时间；DDL 雷达跨视图突出最近、今天与已经逾期的节点
- 更鲜明的八色课程色板，已有旧配色会自动升级，课程、当天与 DDL 的视觉层级更加清晰
- v2.5.0 Outlook 双向同步：每个用户连接自己的 Microsoft 账号，在独立“方寸”日历中双向新增、修改和删除；服务端加密保存令牌并定时合并
- v2.5.0 Android 系统日历桥：APK 创建账号专属的本地“方寸”日历，与小米日历双向修改课程、日程和提醒

- v2.7.0 通用日历与提醒：年、月、周、日视图统一展示日程、任务、期限和课程，课表作为独立模式；支持 Google/Outlook/APK 系统日历增量双向同步，以及安卓精确通知和 24 小时内系统闹钟确认

- 校历与节假日规则：内置 2026 年中国法定节假日预设，并支持学校停课、补课和“按某星期课表上课”
- 自定义学期、教学周、周末显示方式和逐小节作息；内置可编辑的 13 节大学模板
- 课程代码、校区、单双周、任意跨节次，以及为同一课程快速增加另一个上课时段
- 课程的单周停课、调课，课程详情集中显示待完成作业、考试、复习与 DDL，并可一键新建关联任务
- Word DOCX、拾光 JSON 与通用 ICS 两阶段导入：先预览新增、重复、冲突和异常，确认后写入，并支持撤销最近一批导入
- Word 课表会在设备本机读取表格，识别星期、节次、起止时间、课程、教师、教室、周次和纵向合并单元格；旧版 `.doc` 需先在 WPS/Word 中另存为 `.docx`
- PWA 离线缓存、响应式手机/平板/电脑界面、深色模式
- 任务可设置具体时间与提前提醒；浏览器运行期间支持课程、日程和截止通知
- 可连接 Outlook 做真实双向同步；同时保留每个账号独立、可撤销的只读 ICS 订阅地址作为兼容模式
- Android 原生端源码：无地址栏界面、同源云同步、小米/系统日历双向桥、系统通知、精确闹钟授权和开机恢复提醒
- 多用户注册登录、逐账号 SQLite 数据隔离、多端自动同步、版本冲突保护
- 管理员可随时开关注册、查看或停用账号；用户可修改自己的密码，修改后其他设备的旧登录态会自动失效
- JSON 手动备份、服务端最近 30 个历史快照

## 本机运行

需要 Node.js 22.5 或更高版本，不需要安装第三方依赖。

```powershell
npm start
```

访问 <http://127.0.0.1:4173>。第一次打开时建立管理员用户名和至少 8 位的密码；在服务器还没有数据时，本机数据会成为该管理员的第一份云端数据。

运行全部检查：

```powershell
npm run check
```

## 智能收集示例

底部输入框支持直接输入自然语言，并在写入前显示一次简洁预览：

```text
明天下午三点交大学物理作业，重要紧急，提前一小时提醒
明天下午三点到五点参加科研项目组会，重要不紧急，提前半小时提醒
每周二第1-2节 大学物理 1-17周 湖畔校区B12-201
每周二、周五第1-2节 大学物理 1-17周 湖畔校区B12-201，张老师，提前15分钟提醒
建立长期项目：科研论文，12月20日前完成，下一步：阅读三篇综述
```

多行或使用中文分号分隔时可以一次识别多项。当前解析在设备本机完成，免费且不会上传输入文字。代码将解析层独立在 `smart-parser.js` 中，后续可以在不改变数据模型的情况下增加可选的大模型解析器。

同一门课程在多个工作日上课时，可以把“周二、周五”写在同一句里，预览会自动展开成两个上课时段。若要快速体验课表导入，可在“日历 → 同步与导入 → 课表 JSON”选择 `imports/examples/fictional-university-timetable-sample.json`（内置一份完全虚构的示例课表）；导入页会先显示预览，只新增缺失项，并把重复项标出来。

升级前已经进入“待确认”的旧事项不会被静默改写。可在待确认页点击“重新识别”，用当前规则补全日期、时间、优先级和课程；仍有歧义时继续保留待确认状态。

## 数据与同步规则

- 页面上的每次修改都会立即写入当前账号专属的浏览器 `localStorage`，网络中断时仍能工作。
- 登录后，修改会在约 1 秒内自动上传到同源的方寸服务器。
- 服务器使用 SQLite WAL 模式，数据目录默认为项目内的 `data/`。
- 多台设备同时修改同一个云端版本时，后提交的设备不会静默覆盖；界面会要求选择下载云端版本或用本机版本覆盖。
- 下载云端版本前，会把原本的本机数据保存在 `fangcun-pre-cloud-backup` 中。
- 密码通过带独立盐的 `scrypt` 摘要保存；登录态使用随机的 HttpOnly、Secure、SameSite=Strict Cookie。

## 开放注册

旧版单密码数据会在升级时先归入管理员账号 `owner`，原密码不变。管理员登录后会直接进入独立管理后台，不再显示个人四象限界面；后台可以查看注册量、活跃状态、各账号的数据概览和最近同步时间，也可以启用、停用或删除普通用户。删除普通用户会同时删除其云端数据和服务器快照，请谨慎操作。

若要把旧数据交给普通账号 `member`：先确保 `member` 已经注册，再以管理员登录，在“把 owner 的原数据迁移到 member”处执行迁移。服务器会先保存快照；如果 `member` 已经有数据，界面会要求二次确认，不会静默覆盖。迁移后 `member` 会被退出一次，重新登录即可获得旧数据。

建议先只在熟人范围内开放。当前版本有登录与注册频率限制、隐私政策和普通用户自主注销，但没有邮箱验证、找回密码和验证码；如果准备面向完全公开的互联网长期运营，下一步应增加邮箱验证或 Cloudflare Turnstile。

## 部署到 Ubuntu 高端口

当前 `20260911-calendar-v3` 更新使用 [Hermes 发布及 Workbench 升级](docs/workbench-xuan.md)：本地打包与隐私扫描，Hermes 上传 Release 后从原阿里云轻量应用服务器 Workbench 校验升级。下面保留通用首次安装参考。

当前部署方案不会占用或修改 80、443，也不会触碰 Hysteria。默认只监听服务器本机的 `127.0.0.1:18443`，由免费 Cloudflare Tunnel 提供公网 HTTPS。

1. 把整个项目上传到服务器，例如放到 `/tmp/schedule_dimensions`。
2. 在项目目录执行：

```bash
sudo bash deploy/install.sh
```

安装脚本会：

- 将程序安装到 `/opt/fangcun`
- 将数据库放在 `/var/lib/fangcun`
- 创建权限受限的 `fangcun` 系统用户
- 注册并启动 `fangcun.service`
- 自动生成并只在安装终端显示首次登录密码
- 不修改防火墙、安全组、Hysteria 或任何现有反向代理

检查运行状态：

```bash
curl http://127.0.0.1:18443/api/health
sudo systemctl status fangcun --no-pager
sudo journalctl -u fangcun -n 100 --no-pager
```

无需在阿里云防火墙或安全组中放行 18443。Tunnel 从服务器主动向外连接，UDP 443、TCP 80 和 TCP 443 保持原样。

> 若只想临时通过公网高端口验收，可在 `/etc/fangcun.env` 中设置 `HOST=0.0.0.0`，并放行 TCP 18443；但公网 HTTP 不会加密密码和个人数据，也无法可靠安装 PWA，因此不建议长期使用。

不开放公网端口也可以先通过 SSH 隧道安全测试：

```bash
ssh -L 18443:127.0.0.1:18443 admin@你的服务器
```

然后在电脑浏览器访问 <http://127.0.0.1:18443>。

## 备份与升级

在服务器项目目录运行以下命令，会短暂停止服务、复制一致的数据库并立即恢复服务：

```bash
sudo bash deploy/backup.sh
```

备份保存在 `/var/backups/fangcun/`，脚本会清理 30 天以前的同类备份。升级代码时重新上传项目并再次运行 `deploy/install.sh`；已有数据库和登录密码会保留。

## 提醒能力的边界

浏览器通知适合页面或已安装 PWA 正在运行的场景。`android/` 已提供原生 Android 壳和 `AlarmManager` 提醒桥：它会接收网页端未来 90 天的课程与日程，在应用关闭或手机重启后继续注册系统提醒。Android 13 及以上仍需要用户允许通知；Android 12 及以上需要用户在系统“闹钟和提醒”页面允许精确提醒，未授权时会降级为非精确提醒。构建说明见 `android/README.md`。

若希望与 Outlook、Google、Windows 和 REDMI 系统日历互相修改，在方寸中打开“日历 → 同步与导入”：连接 Outlook、Google，并在 APK 中开启“小米 / Android 系统日历”。ICS 私密订阅仍作为只读兼容模式。应用注册、阿里云服务器变量、手机授权、冲突规则和故障排查见 `docs/calendar-sync-guide.md`。

完整的本地打包、Windows 一键上传升级、手动 SCP 命令、服务器验收、APK 构建、REDMI 安装和回滚流程见 `docs/deployment-guide.md`。
